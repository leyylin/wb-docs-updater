# WB Docs Updater

Дашборд на **Streamlit** для массовой привязки разрешительных документов
(деклараций и сертификатов соответствия) к уже существующим карточкам товаров
Wildberries через **Content API v2** — без потери текущих данных карточек.

## Зачем это нужно

Метод `POST /content/v2/cards/update` **полностью перезаписывает** карточку:
если отправить только номер декларации, старые характеристики (цвет, состав,
пол, комплектация), размеры с `chrtID` и габариты сотрутся.

Здесь реализован алгоритм **Safe-Merge**:

1. `POST /content/v2/get/cards/list` — читаем карточки продавца с пагинацией по курсору.
2. Находим карточку по `vendorCode` (артикул продавца).
3. Берём полный исходный объект (`nmID`, `imtID`, `vendorCode`, `sizes`, `dimensions`,
   `title`, `description` и весь массив `characteristics`).
4. Аккуратно добавляем/обновляем характеристики документов: «Номер декларации
   соответствия», «Номер сертификата соответствия», «Срок действия документа»
   (чтобы точно попасть в нужный `charcID`, список характеристик предмета берётся из
   `GET /content/v2/object/charcs/{subjectID}`), а также синхронизируем объект
   `documents` (WB перезаписывает и его — ранее прикреплённые документы сохраняются).
5. Проверяем целостность результата локально и отправляем карточки батчами через
   `POST /content/v2/cards/update` с учётом лимитов (10 запросов/мин, интервал 6 с).
6. Повторно читаем карточки и подтверждаем, что документы применились и данные целы.

## Запуск

```bash
pip install -r requirements.txt
streamlit run app.py
```

Python 3.10+.

## Режимы работы

| Режим | Что происходит |
| --- | --- |
| **Боевой режим (WB API Token)** | Реальные запросы к `https://content-api.wildberries.ru`. Нужен токен категории «Контент». |
| **Демо-режим (Песочница)** | Работает без ключа на локальной мок-базе `mock_wb_cards.json` (1000 карточек в формате реального ответа API: характеристики, размеры с `chrtID`, баркоды, документы). Полный цикл слияния, записи и пост-проверки имитируется в памяти. |

В демо-режиме пауза между батчами автоматически отключается — лимиты есть только
у реального API.

## Формат прайса

Excel (`.xlsx`), первая строка — заголовки:

| vendorCode | declaration_number | certificate_number | expiry_date |
| --- | --- | --- | --- |
| WB-TEST-0001 | ЕАЭС N RU Д-RU.РА01.В.00001/26 | ЕАЭС RU С-RU.АБ12.В.00001/26 | 31.12.2028 |

Поддерживаются также заголовки на русском (`артикул`, `декларация`, `сертификат`,
`срок действия`) и разные форматы даты: `31.12.2028`, `31/12/2028`, `2028-12-31`,
`31 декабря 2028`, дата Excel.

Кнопка **«Сгенерировать Excel»** в сайдбаре создаёт тестовый прайс на 1000 артикулов
(плюс несколько «грязных» строк: дубликаты, пустые значения, несуществующий артикул,
просроченный документ) — его можно скачать или сразу **«Загрузить в память»**.

## Что видно в интерфейсе

* Метрики: всего артикулов в файле, найдено в WB, успешно обновлено, ошибки/не найдено.
* Превью прайса и замечания к данным файла.
* **Инспектор безопасности данных (JSON Diff)**: выбираете артикул — две колонки с
  JSON карточки *ДО* и *ПОСЛЕ*. Подсветка показывает, какие поля добавлены, какие
  изменены, и что все старые характеристики, размеры, название, описание и габариты
  остались нетронутыми.
* Живой лог по фазам (чтение → запись батчами → пост-проверка) и `st.progress`.
* Финальный отчёт: Excel (с подсветкой статусов) и CSV — статус, сообщение, время
  проверки и время пост-проверки по каждому артикулу.

## Статусы в отчёте

| Статус | Значение |
| --- | --- |
| ✅ Обновлено | Документы записаны, пост-проверка пройдена |
| 🟦 Без изменений | Значения из файла уже привязаны к карточке |
| 🟡 Требует проверки | В предмете нет подходящей характеристики / не удалось гарантировать целостность |
| 🟠 Не применено на WB | API принял запрос, но повторное чтение не показало изменений |
| 🔎 Не найдено в WB | Артикула нет среди карточек продавца |
| ⚪ Нет данных для записи | Не указан ни один номер документа |
| ⛔ Ошибка валидации | Пустой/некорректный артикул, неверная дата |
| ♻️ Дубликат артикула | Артикул повторяется в файле, применена первая строка |
| 🔑 Ошибка токена | Токен не принят API |
| ❌ Ошибка API | Ошибка запроса (сеть, лимит, 4xx/5xx) |

## Тесты

```bash
pip install -r requirements-dev.txt
python -m pytest                       # 152 теста, ~1.5 мин
python -m pytest --cov=wb_client --cov=sample_generator   # wb_client.py ≈ 87%
```

Покрыто: Safe-Merge (старые характеристики/размеры/габариты/документы не
затираются, заменяемый документ не оставляет чужой срок), проверка целостности,
курсорная пагинация, ретраи 429/5xx и `Retry-After`, токен-ошибки, отмена,
валидация Excel (дубликаты, пустые артикулы, битые даты), полный цикл на
фейковом WB API, который, как и настоящий, **перезаписывает карточку целиком**,
а также тексты интерфейса (русские названия полей, метрики без расхождений).
